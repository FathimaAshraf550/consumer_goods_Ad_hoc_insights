# consumer_goods_Ad_hoc_insights

## 📌 Project Overview

This project was completed as part of the **Codebasics Resume Project Challenge 4 (Consumer Goods Domain)**.

The analysis focuses on a fictional company, **AtliQ Hardwares**, which operates in India and other markets. The objective of this project is to analyze sales, customers, products, and channels using SQL, and generate meaningful business insights to support management decision-making.

The project simulates a real-world business scenario where stakeholders rely on data-driven insights to identify performance trends, growth opportunities, and areas for improvement.
